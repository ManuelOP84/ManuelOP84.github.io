# Economía de contexto — móvil y nube

- Define primero qué archivo, función o apartado necesitas. Busca rutas/nombres y lee solo fragmentos pertinentes. No cargues todo el repositorio ni el historial por rutina.
- Realiza cambios mínimos, pruebas relacionadas y salida en español de máximo tres líneas (HECHO, PRUEBAS, PENDIENTE). No audites globalmente salvo petición expresa o riesgo crítico.
- Si hay documentos largos, usa extracción local determinista o fragmentos mediante herramientas disponibles, y señala cuando la información sea parcial.
- No instales MarkItDown, MCP, modelos ni dependencias de manera automática. Para imágenes, maquetación o seguridad, la extracción textual puede ser insuficiente.
- No inventes métricas de ahorro de tokens, pruebas reales ni disponibilidad del otro proveedor.
- Solo una IA por encargo, salvo solicitud de revisión fundada. No API de pago ni cambios externos sin autorización.
